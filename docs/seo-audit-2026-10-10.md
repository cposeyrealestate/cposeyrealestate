# SEO and page recognition audit — October 10, 2026

The live homepage is readable by search retrieval. HTTP checks returned 200 for the homepage, robots.txt, and sitemap index. robots.txt permits crawling and advertises the sitemap. The site is Astro 6 with static page generation and Cloudflare hosting. Existing page-specific metadata, canonicals, and JSON-LD are present. These checks do not establish Google index coverage, rankings, penalties, or traffic.

## Confirmed issues and changes

- Three generated sold-property pages were caught by `/portfolio/*` and redirected to the portfolio index. A live request to `/portfolio/203-paul-street/` returned 301 to `/portfolio`. Add explicit 200 rules for all three sold detail pages alongside the existing active-property exceptions.
- `/explorearea/` appeared in the live sitemap despite permanently redirecting to `/hill-country-relocation-guide/`. Exclude exact permanent redirect sources from sitemap generation. Use real article modification dates when supplied.
- BlogPosting and default Article images were relative URLs. The blog index's ten recent-post images had the same issue. Resolve them against the production origin.
- YouTube `contentUrl` values pointed to HTML watch pages, not media files. Remove those values and retain player `embedUrl`.
- Eight city-hub VideoObject records lacked upload dates. Do not emit incomplete video markup when the recorded date is unavailable. Videos remain embedded. Existing components supply dates for some embedded videos; no new dates or times were invented.
- Blog video metadata used article dates and article cover photos instead of the recorded YouTube upload date and video thumbnail. Use the video's own metadata; omit schema when its upload date is unknown.
- Separate Cody's Person entity from the RealEstateAgent business entity. Remove business-only fields and aggregate ratings from the Person. Represent county service areas as AdministrativeArea and place state information in PostalAddress. Point article authors to the about page.
- Metadata hard-cut descriptions at 155 characters, sometimes ending mid-sentence. Preserve complete descriptions. Remove unverified fixed Open Graph dimensions. Allow large image previews. Normalize generated canonical paths to the sitemap's trailing-slash format.
- One credit-score blog linked to a nonexistent first-time-buyer closing-costs article. Point that reference to the existing closing-cost estimator with an accurate label.
- Add `node scripts/audit-seo.mjs` to verify rendered titles, descriptions, canonicals, sitemap destinations, JSON-LD syntax, image URLs, video completeness, and portfolio wildcard redirects before release.

## What still requires account data or editorial work

1. Google Search Console: inspect Page indexing reasons, URL Inspection for representative affected URLs, chosen canonicals, crawl stats, manual actions, sitemap status, and performance over time. Public retrieval cannot replace these reports.
2. Cloudflare: inspect verified-bot handling and security events. A Python default-user-agent request received 403 while curl and search retrieval succeeded. That difference alone does not prove Googlebot is blocked.
3. Video recognition: supplemental embeds on city guides and blogs are not dedicated watch pages. Build a video library with one prominent player per watch page, accurate upload metadata, supporting text/transcript, internal links, and a video sitemap if video search visibility is a goal. Schema fixes alone do not meet the watch-page requirement.
4. Content overlap: repository redirect comments record previous consolidation of near-duplicate AI articles and old-site URL migration. Review current articles using Search Console query and canonical data before further consolidation. Do not infer a penalty from these comments.
5. Distribution: an existing GitHub Action notifies IndexNow for blog changes. Its current signature only detects slug or publication-date changes, so ordinary content edits may not trigger submission. Google does not participate in IndexNow; maintain its sitemap in Search Console and request indexing for important corrected pages.
6. Self-hosted business reviews are not eligible for Google's self-serving review stars. Existing visible testimonials can help visitors, but adding more rating schema will not create eligible stars.
7. Verify business profile details, primary YouTube identity, and review counts against current accounts before changing them. Add Garden Ridge to the centralized service-area list if it reflects the current business profile.

## Validation

Build the production site with `npm run build`, then run `node scripts/audit-seo.mjs`. In the Work runtime, Node's networkInterfaces call throws a system error inside the Cloudflare adapter. A temporary local preload catches that environment-specific call; no adapter workaround is committed. The resulting production build and output audit pass. This is local output validation, not a deployed Cloudflare rules test or a guarantee of indexing.
